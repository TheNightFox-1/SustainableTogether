# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this project (e.g. in any code, scripts, or web components), please **do not open a public GitHub issue**.

Instead, report it privately by emailing: **sustainability@incose.net**

Please include:
- A description of the issue
- Steps to reproduce (if applicable)
- Any suggested fixes

We will respond as quickly as possible and work with you to resolve the issue before any public disclosure.

## Scope

This project currently consists primarily of documentation and system models. Security concerns are most relevant to any code or web components added in the future.

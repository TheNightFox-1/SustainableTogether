Karpathy's pattern · Open Knowledge Format

Three layers, three operations, one gate

Sources are the source code; the wiki is the compiled artifact. Because the sources are immutable, the whole wiki can be rebuilt from them at any time — which is what makes it safe to let an agent own the middle layer.

Layer 1 raw/

The sources

14 PDFs the WG already holds. The registry points at them in place — nothing was copied, so there is one copy of each and no second thing to keep in sync. The agent reads them and never writes them.

The compiled knowledge

Layer 3 CLAUDE.md

The schema

One file: page types, required frontmatter, citation rules, the ingest / query / lint workflows, and the rule that the agent may never set published. Read at runtime — edit it and behaviour changes on the next run.

owner: the WG · 5 minutes to read end to end

The three operations

ingest

Compile a source in

Read it, write its source page, then revise every existing page it bears on — R11 touched six files here. Contradictions get raised, not smoothed. Every touched page drops back to draft: ingest never preserves a human sign-off.

query

Ask the wiki, not the pile

Answers come from the pages, with citations, falling back to raw/ only for detail the wiki does not hold. A good answer is filed back as a page — so asking questions compounds too, instead of evaporating with the chat.

lint

Health-check on a timer

Schema, unresolved citations, uncited claims, orphans, dangling links, stale freshness dates, provenance flags. Deterministic and cheap, so it can run on every commit and re-open only the pages whose flags trip.

Why the gate is not optional

the failure mode

A wiki error does not go away

A RAG error is one wrong answer, in one place, and it disappears when you close the chat. A wiki error becomes a fact that other pages cite and build on. It persists, it spreads, and it arrives wearing a citation. For a scientific working group that is the whole ballgame.

the answer

Curate · draft · review · lint · publish

A human picks the sources. The agent drafts with one citation per claim. A second model instance, with no memory of drafting, checks each claim against its source. A script enforces what a script can. Then a named WG member publishes — and nothing is trusted knowledge until they do.

Tsaneva et al. (2025), Information Processing & Management: the hybrid human-in-the-loop plus LLM check gave the best overall validation, about +5% F1 with minimal human effort. Neither alone won.

what this demonstrator is

One afternoon, eleven sources, sixteen pages, nothing published

Everything here is real: the PDFs are in this repository, the citations carry page and slide numbers, the contradictions were found rather than invented, and the lint report is the script's actual output. What is compressed is the pace — a real pilot accumulates this over weeks, not an afternoon.

The proposal on slide 12 is unchanged by any of it: pilot on one asset, OKF-conformant from day one, gates wired in, reviewed at the next session. If a page never compresses real work, we stop — and we will know why.

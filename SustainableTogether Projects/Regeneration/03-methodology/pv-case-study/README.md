# PV Case Study

The PV-specific instantiation of the generic `../00-regenerative-design-approach.md`. The Task-Force methodology is generic; PV (SolarX → SustainaSun) is the pilot case, and this folder holds the PV evidence and the earlier PV-specific write-up.

| `pv-research-dossier.md` | 9-topic PV research synthesis (agrivoltaics, recycling, EU regulation, perovskite EOL, net-positive cases, IEA-PVPS LCA, pollinator solar, floating PV, community solar), each with an overclaiming-risk section. | Complete |

## How this relates to the generic approach

The generic approach absorbed the 8-phase structure (see the mapping table in `../00-regenerative-design-approach.md` §4). This folder is no longer "the methodology" — it is the worked PV example that the generic method points to. When a real PV project runs the 10 steps, Phase 1–5 content here is the evidence base for Steps 5–6 (map lifecycle, select solutions), and the dossier's overclaiming sections are the honesty check.

# Roadmap

This page describes where SustainableTogether is headed. The project is in early stages — this roadmap reflects current thinking and will evolve with community input.

---

## Current State (Now)

- Knowledge repository with presentations and webinar materials
- MBSE system model for SolarX — physical architecture complete across eight subsystems
- openLCA integration proof-of-concept: a SysML → RDF → ontology → SPARQL pipeline
- Business model and financial model for SustainaSun, built and reviewed
- **Regeneration Task-Force** framed and structured: three research questions, six working groups, and a decomposition that states what counts as an answer to each. See [Projects](projects.md)
- Stakeholder mapping in Phase 2; LLM-Wiki demonstrator complete
- Open source infrastructure (license, contribution guides, GitHub Pages)

---

## Near Term

### Regeneration Task-Force
- Set the numeric targets for the eight desired outcomes — this single decision gates the business-model pricing, the System Dynamics parameterisation, and the measurement thresholds simultaneously
- Confirm the Photovoltaics-as-a-Service revenue architecture and recast the financial model for it
- Build the System Dynamics model — currently the highest-priority missing artefact
- Map the enabling systems and classify which revenue lines can actually be transacted today

### System Model Development
- Finalize the SolarX model that represents the AS-IS state of PV systems including all RFLP layers
- Integration with LCA to automate the assessment and measure the AS-IS environmental impact
- Extend the model with the regenerative layer: ecological requirements, biological and water flows, end-of-life material recovery
- Begin the SustainaSun model — the transformed, sustainable architecture

### Documentation
- Deeper documentation of the SolarX → SustainaSun transformation logic
- Annotated guide to the MBSE model for non-engineers
- ~~Glossary of key terms~~ — done for the Regeneration Task-Force (`Regeneration/GLOSSARY.md`); extend it to cover the whole repository

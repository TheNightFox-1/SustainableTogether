# Roadmap

This page describes where SustainableTogether is headed. The project is in early stages — this roadmap reflects current thinking and will evolve with community input.

---

## Current State (Now)

- Knowledge repository with presentations and webinar materials
- Basic MBSE system model for SolarX (PV system components)
- Open source infrastructure (license, contribution guides, GitHub Pages)

---

## Near Term

### System Model Development
- Finalize the SolarX model that represents the AS-IS state of PV systems including all RFLP layers.
- Integration with LCA to automate the assessment and measure the AS-IS envrionmental impact. 
- Begin the SustainaSun model — the transformed, sustainable architecture
- Add lifecycle and sustainability metrics to the model

### Documentation
- Deeper documentation of the SolarX → SustainaSun transformation logic
- Annotated guide to the MBSE model for non-engineers
- Glossary of key terms (MBSE, SysML, sustainability concepts)

---

## Medium Term

### Method
- How to automate LCA with SysML v2?
- How to create a SysML v2 model?
- How to design a circular system?


### MBSE Models and Tools
- Formal SysML model files 
- Small applications to integrate between tools and domains, e.g.: LCA, Business model, etc.


---

## Long Term

- A replicable framework that other companies can use to assess and transform their own systems
- Integration with real-world sustainability standards (ISO 14001, GRI, INCOSE frameworks)
- Community of practice around sustainable systems engineering

---

## How to Influence the Roadmap

Have an idea for what we should build next? Open a [Feature Request](https://github.com/TheNightFox-1/SustainableTogether/issues/new?template=feature_request.md) or start a [Discussion](https://github.com/TheNightFox-1/SustainableTogether/discussions).

This is a community project — the roadmap is shaped by the people who contribute to it.
